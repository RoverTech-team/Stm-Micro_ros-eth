2 — Root Cause

  • Two Caddyfiles drift, compose still declares HOST_IP env unused
  • resolve-compose.sh hil-host typo maps to wrong compose

3 — Target Architecture (Resilient)

Wildcard bind :5050 + tls internal {on_demand} → binds 0.0.0.0:5050, mints cert for any Host/IP on demand. Works for localhost, 127.0.0.1, any LAN IP, mDNS. Two files keep distinct backends: Caddyfile → microk3:5050 (bridge), Caddyfile.host → 127.0.0.1:5051 (host). No HOST_IP needed; DASHBOARD_PORT kept for mapping.

{
    servers { protocols h1 h2 }
}
:5050 {
    tls internal { on_demand }
    reverse_proxy 127.0.0.1:5051 { flush_interval -1 }
}
# Caddyfile (bridge): same but reverse_proxy microk3:5050 + optional :443 block
