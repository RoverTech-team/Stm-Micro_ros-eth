05 Cert volume reset (one-time)

Caddy stores certs in Docker volume `caddy_data` (`/data/caddy/certificates/local/{10.42.0.1,127.0.0.1,localhost,192.168.3.22}` seen via `docker exec -u root caddy ls -la /data/caddy/certificates/local/`). After `HOST_IP` change, old `192.168.3.22` cert remains and renewal is throttled (`storage cleaning happened too recently; skipping`). Reset forces fresh cert for `10.42.0.1`.

# inspect (read-only, verifies)
docker volume inspect jetson-orin-nx_caddy_data
docker exec -u root jetson-orin-nx-caddy-1 ls -la /data/caddy/certificates/local/

# reset (destructive, only caddy_data)
docker compose -f docker-compose.jetson.yml down   # stops caddy + microk3 (microk3 healthy, will restart)
docker volume rm jetson-orin-nx_caddy_data jetson-orin-nx_caddy_config
# alternative surgical: rm only stale dir inside running container
docker exec -u root jetson-orin-nx-caddy-1 rm -rf /data/caddy/certificates/local/192.168.3.22
